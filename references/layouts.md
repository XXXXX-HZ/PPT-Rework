# 版式目录 — 按页面职责选，不要套同一个

先问「这一页要替听众做什么」，再选版式。**相邻两页不用同一个版式。**
所有坐标基于 13.333 × 7.5 画布，常量见 `design-system.md` §4。

```js
const M = 0.65, W = 13.333 - 2 * M;   // 0.65" 边距，12.033" 可用宽
const TOP = 1.75, BOT = 6.60;          // 内容区上下界
```

---

## L0 · 公共骨架

每个正文页都先跑这两段，保证全场对齐一致：

```js
function content(actionTitle) {
  const s = pres.addSlide();
  s.background = { color: PAPER };
  s.addText(actionTitle, {
    x: M, y: 0.33, w: W, h: 0.85, isTextBox: true, margin: 0,
    fontFace: FONT, fontSize: 26, bold: true, color: PRIMARY,
    align: 'left', valign: 'top'          // 左对齐：多行结论句居中会破坏网格
  });
  s.addText(String(++pageNo), {
    x: 13.333 - M - 0.5, y: 7.02, w: 0.5, h: 0.25, isTextBox: true, margin: 0,
    fontFace: FONT, fontSize: 10, color: MUTED, align: 'right'
  });
  return s;
}

function source(s, txt) {              // 口径 + 样本量 + 时间范围 + 排除项
  s.addText(txt, {
    x: M, y: 6.90, w: W - 0.6, h: 0.44, isTextBox: true, margin: 0,
    fontFace: FONT, fontSize: 12, color: MUTED, valign: 'top'
  });
}
```

⚠️ 每个 `addText` 都要 `isTextBox: true`（否则读屏软件读成图形）和 `margin: 0`
（否则文字框内边距会让它和同 x 的形状对不齐）。

---

## L1 · 封面

**职责**：告诉听众这是什么、谁讲、什么时候。

满底 `PRIMARY`，白字。主标题 36–40pt 起于 y=2.05；副标题 19pt 于 y=3.65；
作者/单位/日期 15pt 于 y=5.35。**标题宽度留 1.2" 余量**（`w: W - 1.2`），
避免长标题贴到右边缘。

---

## L2 · 分节页 Divider

**职责**：切换话题，给听众一个换气点。>12 页的 deck 必须有。

满底 `PRIMARY`。三层：
- kicker（`PART 1` / `APPENDIX`）16pt Bold，`charSpacing: 2`，浅色，y=2.25
- 大标题 32–36pt Bold 白字，y=2.75
- 可选说明 16pt，y=4.0，宽度只给 `W - 3.0`（右侧留大片空——这是分节页该有的呼吸感）

**分节页可以承载范围声明**。例如「本节只覆盖早期付费者，因为晚付费者会被观察窗口右截断」——
这种方法论交代放在分节页比单开一页更自然。

---

## L3 · 数字墙 Stat Row

**职责**：一句话交代规模/现状。适合「为什么这事重要」页。

3–4 个数字横排，**其中一个用 `EMPHASIS` 色**（就是你想让人记住的那个）：

```js
const cw = 2.72, gap = 0.31;   // 4*2.72 + 3*0.31 = 11.81 <= W(12.033) ✓
// 数字：y=2.05, h=0.95, 32pt Bold（4 列时不要用 36pt——11 字符的
//       「$1.02–$1.14」在 2.72" 宽里会折行）
// 标签：y=3.05, h=0.90, 15pt, 两行（用 \n）
// 下方一句话：y=4.55, w=W-1.4, 20pt, lineSpacing:30
```

**数字和标签必须分成两个 `addText`**——同框会按最大字号算行高，一定溢出。

---

## L4 · 双问题 / 双选项

**职责**：把要回答的问题摆明，或对比两条路径。

两个浅底方框（`F2F6FA` 填充 + 1px `E7E6E6` 描边，**不加投影不加单边色条**）：

```js
const bw = 5.8, gap = 0.433;           // 0.65 + 5.8 + 0.433 + 5.8 = 12.683 ✓
const x  = M + i * (bw + gap);
// 框：y=2.0, h=3.2
// 标记 Q1/Q2：x+0.38, y=2.3, 18pt Bold, EMPHASIS
// 标题：     x+0.38, y=2.85, w=5.04, 22pt Bold, PRIMARY
// 说明：     x+0.38, y=3.85, w=5.04, 16pt
```

⚠️ 算宽度时**把间隙也算进去**再验证右边缘 ≤ `13.333 - M`。
这是最常见的出血来源（少算 0.02" 也会被检查脚本抓到）。

---

## L5 · 图 + 解读（数据页主力版式）

**职责**：呈现一个发现。**一页一个 exhibit。**

左图右文，比例约 7:3：

```js
// 图表：x=M, y=1.75, w=8.30, h=4.25
// 右栏：x=9.25, w=3.45
//   ├ 大数字 callout   y=1.90, h=0.62, 32-34pt Bold EMPHASIS
//   ├ 一句话解释       y=2.55, h=1.20, 16-17pt
//   ├ 次要观察/警告    y=3.90, h=1.50, 16pt
//   └ 结论行           y=5.20, h=0.95, 16pt Bold EMPHASIS
// source：             y=6.90
```

**右栏是这个版式的价值所在**：图给证据，右栏给「所以呢」。
右栏只写图上看不出来的东西——桶宽不等的警告、和其他数据的关联、行动含义。
**不要在右栏复述图上已有的数字。**

---

## L6 · 对比揭示（双系列反转）

**职责**：当两个分布形状相反时，这是全场最有说服力的一张图。

同 L5 的几何，但图表用两个语义不同的系列：

```js
chartColors: [PRIMARY, EMPHASIS]      // 而不是 [PRIMARY, ACCENT]
// 例：系列1 = 人数占比，系列2 = 收入占比
```

**如果原稿把这种对比拆成了两张并排图，合并它。** 两个分布放在同一坐标系里，
「两端反转」的形状一眼可见；拆成两张，听众要在脑子里做对齐，说服力掉一半。
这通常是重构中收益最大的一处改动。

---

## L7 · 表格页

**职责**：精确数值比较。**只在具体数值本身重要时用表格**，展示趋势/分布一律用图。

```js
// 表：x=M, y=1.85~1.95, w=W
// 表头：PRIMARY 填充 + 白字 Bold 13pt，居中
// 单元：13pt，首列左对齐其余居中
// 边框：{ type:'solid', pt:0.75, color:'E7E6E6' }  ← 极淡，不要黑框
// 下方结论段：y=5.15, 17pt, lineSpacing:26
```

- 列数 ≤ 7。更多就砍列或转置
- **焦点单元格用 `EMPHASIS` 加粗**，弱化的行用 `MUTED` —— 让表格自己指路
- 表头两行的写 `\n`，`rowH` 第一项给 0.6–0.75
- 小样本必须在 source 行写出来：`n = 11–62，campaign 级差异仅供参考，未做显著性检验`

---

## L8 · 讨论 / 边界页（双栏）

**职责**：说清这个分析意味着什么、以及做不到什么。**这一页不能省。**

```js
// 左栏 "结论意味着什么"：x=M,    y=1.75 标题 19pt Bold PRIMARY
//                        y=2.30, w=5.90, 16pt bullets
// 右栏 "这个分析说不了什么"：x=7.00, y=1.75 标题 19pt Bold EMPHASIS
//                        y=2.30, w=5.70, 16pt bullets
// bullet: { bullet:true, breakLine:true }，最后一条不加 breakLine
// 段间距用 paraSpaceAfter:14，不要用 lineSpacing（会撑出巨大空隙）
```

右栏标题用 `EMPHASIS` 色——视觉上承认「这里是我的软肋」比藏起来更可信。

---

## L9 · 结论页（最后一页正文）

**职责**：Q&A 全程挂在屏幕上的那一页。

编号 + 结论句 + 证据，三条：

```js
pts.forEach((p, i) => {
  const y = 1.8 + i * 1.32;
  // 序号 1/2/3：x=M,        y,        w=0.45, 24pt Bold EMPHASIS
  // 结论句：    x=M+0.55,  y,        w=11.4, 21pt Bold PRIMARY
  // 支撑证据：  x=M+0.55,  y+0.45,   w=11.4, 16pt MUTED-ish
});
// 联系方式：y=6.20, 14pt MUTED
```

**结论句必须带数字**。「提升转化」是废话，「把首单弹窗从 D3 提前到 D1」是结论。

---

## L10 · 附录

**职责**：Q&A 弹药。正文放不下但可能被问到的东西。

标题写 `Appendix A — <内容>`，明确标记。
一页可以放两张表（上下堆），或一张表 + 一段说明（左表右文，表宽 7.6"）。
附录页**不计入 1 页 1 分钟的预算**。

---

## 版式分配自检

排完后把版式序列写出来看一眼：

```
L1 L3 L4 L7 | L2 | L5 L5 L5 L7 | L2 | L7 L6 L5 | L8 L9 L7 | L2 | L7 L7
```

- 相邻两页同版式了吗？（L5 L5 连排可以，但超过三页就要插一个 L7 或 L6 换气）
- 分节页 `L2` 的间隔均匀吗？
- 有没有 `L8`（边界页）和 `L9`（结论页）？**缺任何一个都不算完成。**

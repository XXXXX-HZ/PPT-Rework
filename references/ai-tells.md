# AI 痕迹清单 — 检测与改法

这是**兜底清单**。先做 SKILL.md 里的正向工作（注入具体性），再用这份表查漏。
每条给「现象 → 为什么是 slop → 改法」。带 `[auto]` 的能被 `scripts/smell.py` 自动检出。

---

## A. 视觉层

### A1. 标题下的装饰横线 `[auto]`
标题下面一根彩色短线或细条。
**为什么**：这是 2022–2024 年 AI 生成 PPT 的头号签名，训练语料里密度极高。人做的 deck 几乎不这么干。
**改法**：删掉。用留白建立层级——标题和正文之间留 0.35–0.5 英寸即可。

### A2. 通栏色条 / 侧边竖条 / 卡片单边描边 `[auto]`
页眉页脚的整宽色带、左边缘的竖色条、卡片左侧的 4px accent border。
**为什么**：Material/Tailwind 时期的烂大街组合，已经是纯视觉噪音，不携带任何信息。
**改法**：要区分色块就用极淡的底色填充（如 `F2F6FA`）或 1px 极淡灰描边，不要单边强调条。

### A3. 彩色圆圈里的图标 `[auto]`
每个小标题旁边一个圆形色块，里面一个图标。
**为什么**：AI 稿的通用「填充视觉」手段，图标本身不承载差异化信息。
**改法**：**只保留承载信息的图标**。装饰性的全删。真需要图标就用线性图标裸放，不加圆底。

### A4. Emoji 当图标或 bullet `[auto]`
🎯 💡 ✅ 🚀 出现在小标题或列表前。
**为什么**：训练语料里「不够专业就用 emoji 凑」的病。在任何正式场合都立刻掉格调。
**改法**：全删。例外只有一个：用户的品牌/产品本身就用 emoji（如 Notion 风），或受众是儿童。

### A5. 通用科技蓝 / 紫渐变 `[auto]`
`#2563EB` `#1E40AF` `#3B82F6` 系的「SaaS 蓝」，或紫→蓝的渐变背景。
**为什么**：训练语料里「科技感」的万能公式，出现在每一个 AI/SaaS 落地页。用了 = 主动放弃识别度。
**改法**：换 `design-system.md` 里的锁定色板，或用户品牌色。
**例外**：品牌本身就是这个色——此时它不是 slop，是签名。

### A6. 圆角卡片 + 投影 `[auto]`
所有内容块都裹在带 drop shadow 的圆角矩形里。
**为什么**：为了「高级感」加阴影，结果瞬间变成 2015 年的商务 PPT 模板。
**改法**：图片最多 1–4px 微圆角，**不加 box-shadow，不加边框**（除非 1px 极淡灰）。
内容块用留白和对齐区分，不用容器。

### A7. 每页同一个版式
全篇都是「标题 + 三个并排卡片」或「标题 + 三条 bullet」。
**为什么**：真人做 deck 会根据这一页要干什么选版式。全篇一个版式 = 没有做过页面级判断。
**改法**：读 `layouts.md`，按页面职责分配版式。**相邻两页不用同一个版式**。

### A8. 重字重的大标题
Display 尺寸用 700/800/900。
**为什么**：字号已经建立了层级，再加极粗字重是层级冗余，视觉上发胖。
**改法**：大字（32pt+）用 Regular 或 Light；加粗留给需要在小字里跳出来的地方。
中文尤其明显——粗黑体大字是廉价感的主要来源。

### A9. 正文居中
段落和列表居中排。
**为什么**：居中正文没有稳定的左侧读取边，行长一变阅读就断。AI 稿常用它来「看起来整齐」。
**改法**：正文一律左对齐。只有独立的大字 statement 页可以居中。

### A10. 均匀用力
每一页精致程度一样，没有重点页。
**为什么**：真人做 deck 会在 1–2 页上花掉一半时间，其余页干净利落。均匀 = 没有判断。
**改法**：**一个细节做到 120%，其余做到 80%**。挑最重要的那张图做到极致，其他页保持克制。

## B. 内容层

### B1. 主题标签当标题 `[auto]`
「概述」「现状分析」「Results」「Key Takeaways」「Next Steps」「总结」。
**为什么**：标题是 deck 里信息密度最高的位置，用它放一个分类名 = 浪费掉最贵的位置。
**改法**：改成**带具体信息的完整陈述句**。
- ❌ 现状分析 → ✅ 付费转化率连续三个月停在 2.5%，卡点在首日
- ❌ Key Takeaways → ✅ 两个窗口决定了变现上限：前 48 小时和第二笔订单

**自检**：只读全部标题，能不能读出完整论证？不能就是标题没写对。

### B2. 每页恰好三条，语法完全平行 `[auto]`
每页都是 3 个 bullet，每条都是「动词 + 名词 + 补语」。
**为什么**：三段排比是 LLM 的默认输出形态。真实内容的条数由内容本身决定。
**改法**：主动破坏。这页 2 条，下页 5 条，再下页一段话加一张图。
**如果某页确实就是 3 条**——那保留，但不要每页都是。

### B3. 空洞动词与套话 `[auto]`
leverage / streamline / robust / comprehensive / seamless / holistic / empower /
赋能 / 抓手 / 闭环 / 全方位 / 深度融合 / 持续优化。
**为什么**：这些词在训练语料里高频但零信息量，是「说了等于没说」的标记。
**改法**：换成具体动词，或直接删。「持续优化转化流程」→「把首单弹窗从 D3 提前到 D1」。

### B4. 数字没有出处 `[auto]`
「转化率提升 30%」，没有口径、没有样本量、没有时间范围、没有来源。
**为什么**：**这是 AI 稿最致命也最容易修的特征。** 真人做分析一定知道数字从哪来，
而且会写出来保护自己。没有出处 = 没有人对这个数字负责。
**改法**：每一页有数据的地方加 source 行（12pt，灰色，页脚）：
口径 + 样本量 + 时间范围 + 排除了什么。
> 例：`Apr 2026 cohort，早期付费者 n=2,665。中位数口径，因均值受 top 1% 支配。`

### B5. 没有边界 / 没有局限
通篇只有结论，没有一句「这个分析做不到什么」。
**为什么**：真实分析一定有妥协。全是肯定句 = 要么没想过，要么在藏。
**改法**：**加一页专门写边界。** 样本限制、口径妥协、没做显著性检验、观察窗口截断、
小样本单元格。这一页的存在本身就是最强的「人做的」信号。

### B5b. 编造的 stat / quote 当装饰
为了填满版面造一个「行业平均 73%」或一句无出处的名人名言。
**为什么**：装饰性编造是 slop 的典型形态，而且是会出事的那种。
**改法**：留白，或问用户要真内容。**宁可空着也不要编。**

### B6. Bullet 复述标题
标题说「转化率在下降」，第一条 bullet 写「转化率呈下降趋势」。
**为什么**：AI 展开时容易把标题重说一遍。信息重复 = 浪费听众注意力。
**改法**：标题给结论，bullet 给**证据或机制**，不给同义改写。

### B7. 句长均匀
每句话都是 20–25 字，节奏完全一致。
**为什么**：人写东西句长天然起伏。均匀的节奏是生成文本的听感特征。
**改法**：主动混入短句。一个词的强调句也可以。

### B8. 以「谢谢」或空白页结尾 `[auto]`
最后一页写「Thank You」「谢谢聆听」，或者干脆空白。
**为什么**：Q&A 全程这一页挂在屏幕上。挂一个「谢谢」= 浪费掉最长的屏幕时间。
**改法**：最后一页是**结论页**。听众提问时抬头看到的应该是你的三条结论。

## C. 结构层

### C1. 没有论证，只有话题列表
每页独立成立，顺序可以随便换，换了也不影响理解。
**为什么**：这是 AI 按大纲生成的直接后果——它在填充话题，不在推进论证。
**改法**：选一条主线（SCR：现状→矛盾→解法 / 漏斗 / 结论先行），
每页在这条线上有**唯一**的位置。测试：任意两页交换顺序，如果读起来没区别，说明没有线。

### C2. 缺少必要页面
没有问题定义页、没有方法/口径页、没有边界页、没有结论页。
**改法**：补齐。一份能讲的 deck 的最小骨架是：
`封面 → 为什么重要 → 要回答什么 → 怎么测的 → 发现（N 页）→ 边界 → 结论`。

### C3. 每页密度一样
每页都是满的，或者每页都是空的。
**改法**：让节奏起伏。重点页给满，过渡页给白。分节页只放一句话。

### C4. 页数与时长不匹配
20 分钟的场合给了 40 页。
**改法**：**1 页 1 分钟是上限不是目标**。超出的移到附录。
附录页明确标 `Appendix A / B`，是 Q&A 弹药，不是正文。

## 自检顺序

改完后按这个顺序过一遍，比从头读全文有效：

1. **只读标题** —— 能读出完整论证吗？（B1 / C1）
2. **找 source 行** —— 每个数字都能追溯吗？（B4）
3. **翻到最后一页** —— 是结论还是「谢谢」？（B8）
4. **有没有边界页？** （B5）
5. **相邻两页版式一样吗？** （A7）
6. **跑 `smell.py`** —— 分数比输入低了吗？

前四条过不了，视觉再干净也是 AI 稿。
